# Ticket Booking System

A Java DSA project with a Swing GUI.

## Data structures used
- HashMap: look up a booking by ID
- HashSet: stop double booking of seats
- Binary Search Tree: list bookings sorted by seat
- Priority Queue (heap): waiting list, VIP and senior first
- Stack: undo the last cancellation

## How to run
javac *.java
java App

## Features
- Book and cancel tickets
- Waiting list with priority
- Undo last cancellation
- Separate Customer and Admin windows
